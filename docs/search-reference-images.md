# 联网参考配图

搜索可以在同一轮文字回复下方附最多一张图片。点击整张图片卡片会在新标签页打开它的来源网页。

## 何时出图

`search_web` 新增可选参数 `includeImage`，默认关闭。模型判断视觉参考有助于理解，或用户明确需要看图时，才选择 `true`。单纯文字已经能说明的问题继续使用文字。

本功能复用已有方舟联网请求。图片只取供应商正式网页引用中的 `cover_image.url`，来源链接取同一引用的 `url`。不会为补图再次搜索，也不会额外调用一个整理模型。

官方 Responses 接口定义了 `output[].content[].annotations[].cover_image`，包含 `url`、可选宽高；[官方字段说明](https://docs.volcengine.com/docs/ark/create-model-responses-api?lang=zh)。封面图只在部分内容源中出现，见[联网插件数据结构](https://docs.volcengine.com/docs/ark/online-plugin-data-structures?lang=zh)。它是网页配图，不保证是事件现场照、商品实拍或专门图片搜索的最佳结果。

搜索没有返回图、图片地址无效、搜索失败时，沿用正常文字流程。图片加载失败也保留来源链接。界面统一标为“来源网页配图”。

## 消息与回放

图片以结构化 `attachments` 保存到助手消息，与 `text` 和分气泡 `parts` 分开。旧消息新增的是可空列，已有文本、记忆和概括不重写。图片地址与二进制内容不拼进记忆提取正文。

只有本轮实际执行、明确请求配图的搜索才会产生新附件。普通追问不会因为上轮有图而自动再发一遍。刷新、读取历史以及同一请求ID回放使用已保存附件，不重搜、不重复计费。

文字答案正常完成并保存后，再发送图片附件事件。仅有承接、模型失败或取消时不会把候选图当作已完成回复发出。图片卡使用供应商图片地址，服务端不代理下载或抓取来源网站；点击来源链接与图片加载均不携带本页referrer。

## 当前边界

模型决定是否需要视觉参考；本轮可用封面中选择最多一张。模型不能自由编写图片链接作为附件，界面也不解析模型文本中的Markdown图片。图片与具体问题的贴合程度仍取决于搜索来源，当前没有增加视觉识别模型或独立图库检索服务。

本轮一次独立真实联网核验返回3条资料、0张原生封面，说明此通路不能保证需要图时一定有图；没有为取得成功样本继续搜索。图卡、点击来源、刷新、普通后续不重贴、无图与坏图回退，使用独立模拟搜索结果和公开样图完成浏览器验收；窄屏390像素未见横向溢出。这些验证不等于真实搜索配图覆盖率或图片语义准确率。
