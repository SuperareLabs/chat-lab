# 本地角色

打开 [ChatLab](http://localhost:4334/)，在角色列表切换。免密码，主模型仍是 DeepSeek1017经济版、关闭思考。已有聊天和记忆保留。

当前上架：苏清月、鳄鱼爸爸、大肥鱼、林晚晴。其余 11 位角色已下架，不能继续发起聊天；提示词、已有聊天和记忆保留。下架清单在 `config/default-agents.json` 的 `retiredAgentIds` 中，种子及以下设计文档留作归档。

[苏清月完整提示词](lin-xiaoman-role-setting.md)含日常回复规则和优化前后试聊。苏清月沿用林小满的角色 ID 和已有会话。

- [沈知衡完整提示词](shen-zhiheng-role-setting.md)：32岁，做旧建筑修复。话少、有点冷，别人讲一堆，她可能只挑一句回；熟了偶尔损人，也会关心。六项和例子都已重写。
- [林晚晴完整提示词](lin-wanqing-role-setting.md)：30岁，出版社编辑。温和、有自己的看法，会接暧昧，也愿意主动逗你；对方不想调情时，就正常聊天。

普通招呼就回个招呼，简单应声和告别也可以一句结束。角色愿意聊天、可以暧昧，不等于每轮都要拉话题或追问。明确让她多讲时，才继续展开。

林晚晴 v5：没看懂、不知道怎么回或没什么可接时，可以整条只发“？”或“？？”，不再硬猜、硬逗或解释自己为什么没看懂。对方补清楚再聊，认真提问仍正常答。

两份提示词都直接写她怎么听、怎么回、什么时候多说、什么时候拒绝，例子是原创聊天，不是用户旧事。林晚晴是新增的成年角色，和沈知衡分别保存会话与记忆。文字头像不是人物照片。

改源码版时，编辑对应Markdown里两个标记之间的正文，再运行 `node scripts/sync-local-personas.mjs`，同步到SOUL和默认种子。原 `sync-shen-persona.mjs` 命令仍只同步沈知衡，也保留原来的审阅副本参数。

未手动改过的默认角色会原位更新；私人编辑保留。需要测试新版时，先在页面的角色设定中确认正文，建议新建会话，旧记录不用删除。

本轮合成试聊和界面验收保存在本机 `verification/local-personas-v4-*`。试聊用于找问题，不把短句或测试项数当作人物效果分数。
