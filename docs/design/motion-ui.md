# Chat Lab · 聚焦聊天的轻量界面

当前应用版本1.1.2，封版分支`version1.1.2`，标签`v1.1.2`。本轮界面由`design/motionsites-ui`整理，1.1.0封版分支与标签保留。

## 当前布局

去掉顶部Chat Lab品牌栏、标语与播放开场按钮，仅保留角色、用户、会话等必要操作。聊天区是主要画布，左右分别保留上下文与记忆的调试能力。桌面三栏为`minmax(210px,.82fr) minmax(460px,3fr) minmax(230px,.9fr)`，16px间距；主体高度采用`calc(100dvh - 128px)`，减少顶部留白，增加聊天空间。窄屏仍由聊天在前、辅助面板在后，已有快捷入口和表单保持不变。

维持暖纸色`#f3f1eb`、白色聊天画布、深墨色主操作和小面积苔绿强调。保留本地Manrope英文字体、已有角色素材、角色图鉴及真实提示词详情。不再追加装饰或营销层。

## 每次刷新自然进入

由`motion-ui.css`提供纯CSS进入动画：工具栏、聊天、辅助面板柔和淡入并上移少量像素，聊天优先，总长不超过600ms。每次刷新重新执行；没有首进存储标记，没有全屏片头、播放按钮或专用JavaScript，也不限制输入和焦点。`prefers-reduced-motion: reduce`时直接显示。动画不接触API、角色设定、会话或记忆。

## 验证与数据

沿用原前端功能契约，使用独立模拟服务检查桌面与手机布局、连续刷新确实重播、减少动态效果直接展示、聊天和选择操作可用。上线前备份当前源码及SQLite，核对升级前后业务表内容一致。正式用户、角色、会话和记忆不因这轮纯前端精简被重置。
