# Chat Lab · 对话，自有回响

本轮只调整现有实验台的呈现与进入动画，保留聊天、角色配置、工具、记忆及用量接口。基于 MotionSites Web Builder 的参考分析、精确规格和截图复核流程；参考 Intelligence Layer 的克制层级、Tech-Forward 的白底黑字与错峰入场，以及 Email Landing Page 的三栏工作空间关系，采用原创标志与现有角色素材。1.1.0 的封版提交与标签保持不动，开发分支为 `design/motionsites-ui`。

## 方向

气质：安静、清晰、有温度。页面是正在工作的产品，聊天是主角，左右面板为理解与核对提供辅助。标志由两个相向的对话轮廓与一个点构成，开场让点成为连线、连线成为对话；最后让位于真正的聊天。没有营销区块、虚构数据、自动推荐问题或角色话题逻辑。

桌面采用暖纸底与白色聊天画布，深墨色用于品牌与主要操作，苔绿用于选中、成功与轻微强调。同一页面最多三类强调元素：主操作、选中态、消息。背景仅加入低透明度的细线质感，工作区没有循环动画或模糊大背景，正文保持平静。

## 字体与颜色

英文字体使用本地 Manrope，字重400—700；中文采用系统 PingFang SC / Microsoft YaHei / Noto Sans CJK SC。数字使用 tabular-nums，原始请求与提示词沿用系统等宽。Manrope 文件由 Google Fonts 获取并随附 OFL 许可，无运行时字体请求。品牌英文字34px/1.05、650、tracking -.055em；中文产品名13px/1.5、500。面板中文标题14px/1.3、650，上方英文标签9—10px、tracking .12em。主聊天正文15px/1.75，侧栏正文12—13px/1.8，辅助说明11px/1.65。

颜色：page `#f3f1eb`；surface `#fcfbf8`；paper `#ffffff`；ink `#263025`；muted `#626b60`；border `#dedfd6`；line `#e7e7de`；accent `#53654c`；accent-soft `#e9eddf`；assistant `#f1f3ed`；user `#e6ecd8`；primary `#293328`；error `#934d42`。主要文字清晰，面板中不叠加照片或背景视频。焦点2px实线、offset3px；选中文本使用柔和苔绿底。

## 页面骨架

1440×900时，工作区宽1376px，左右各32px，顶部24px。品牌行64px，底部20px；工具栏高68px，底部20px。主体可用高度 `calc(100dvh - 208px)`，最低520px，最高940px；横向3栏为 `minmax(210px,.92fr) minmax(420px,2.64fr) minmax(230px,1fr)`，间距20px。中间聊天圆角22px、白底、1px边框、阴影 `0 12px 42px #2730210c`；侧栏背景更轻，不添加同等阴影。品牌与工具栏的边缘同主体对齐。

品牌左侧原创标志36px，右侧 `Chat Lab.` 英文字标与完整中文产品名。右侧仅保留一句短标语和44px高的“观看开场”按钮。工具栏使用半透明白底、16px圆角、1px描边；Agent在左，用户/会话/新会话在右，以间距而非大量小容器分组。所有交互目标最低44px。新会话为深墨色按钮，创建角色为次级描边按钮，用户新增为轻图标按钮。

面板头部高74px，上方小英文 CONTEXT / MEMORY，下方中文名称；图标32px，右侧小圆点仅作装饰。上下文内容外边距14px，折叠行最低44px，背景色块减少，通过行距和细分隔线区分。记忆按日期分组，类型与时间在一行中退后，摘要13px；概括与实际记忆保持已有语义和来源。活跃/归档/撤回保持三项等宽分段控件，选中项白底与微阴影，不改变筛选逻辑。

聊天头部高76px，头像44px、圆角14px，名称16px，说明12px且单行省略。消息区padding 26px 24px，消息行间距24px；助手浅灰绿泡、用户浅苔绿泡，圆角16px/连接处5px，padding 12px 15px；最长宽度86%。保留分条/工具承接节奏，不为设计拼接或拆分模型输出。输入区padding 0 22px 16px，输入框最小64px、圆角16px，聚焦时细绿边与2px浅色光环。发送44px深色按钮；其下用量仍保持一行，悬浮和点击显示原有详情，数字11px。

## 角色图鉴与弹窗

角色图鉴是人物档案：左侧约36%展示已有头像/剪影与大名称，右侧64%展示实际保存的设定原文。既有头像、参考音与受众信息保留，原文可以展开；禁止恢复过时的多维展示文案。提示词详情仍由后端返回，左侧为层级导航，右侧为可滚动文档。顶栏、tab、底栏与编辑控件维持44px点击范围。图鉴在手机上改为纵向阅读，按钮不压缩到不可点。

创建用户、创建/编辑角色的dialog采用24px圆角、白色内层、细边框；背景遮罩 `#26302542` + blur8px。用户表单保留姓名、年龄、兴趣；角色表单仅名称与完整角色设定，保留换行和冲突草稿逻辑。表单label12px/600，input高46px，textarea正文14px/1.85，操作按钮44px。小高度屏幕弹窗整体滚动，操作区不被截断。错误信息位于原字段附近，保留现有role=alert。

## 开场与动效

独立模块使用原生dialog，不依赖API、模型或外部库。首次进入同一标签页会话展示开场，sessionStorage键为独立版本键；受限存储不导致阻塞。两只对话线条在0—700ms从位移16px/透明0到位移0/透明1，SVG描边按路径绘制。标题在240ms开始，600ms内淡入与上移；说明在600ms开始，400ms内淡入。1150ms开始350ms退场，总时长约1500ms；随后工作区轻微错峰出现，主聊天先于辅助面板。默认缓动 `cubic-bezier(.22,1,.36,1)`。

右上角“跳过开场”始终可点且至少44px；Esc直接结束，自动结束后清理timer、dialog和焦点限制。重播按钮可随时观看。切后台或BFCache返回时收拢残留状态。`prefers-reduced-motion: reduce` 时默认直接展示工作区；手动重播仅静态或短淡入。JavaScript未执行时应用仍默认可见；不能以永久opacity0等待动画成功。

按钮hover仅背景、描边与不超过1px的微位移，140—180ms；消息沿用180ms出现；dialog 200ms opacity/translateY8px。工作区没有持续漂浮、旋转、闪烁或鼠标跟随，模型生成中的原有状态动效保留，reduce时关闭。

## 响应与验收

≥1101px保留三栏；≤1100px聊天占整行，两个辅助面板排列在下方并保留快捷定位；≤650px整体边距12px，品牌行缩到60px、标语隐藏，工具栏分为角色行和用户/会话行，控件不低于44px。聊天高度至少440px并尊重dvh；辅助面板纵向排列。320px不横向溢出，长角色名、模型名、JSON与提示词断行；底部费用详情浮层不得超视口。短高度≤720px减少品牌留白，优先保留输入框和主要操作。

验收使用独立4335本地模拟服务：真实运行原API和SQLite，所有模型与搜索为合成响应，不操作4333正式数据、不付费。拍摄1440×900、1280×800、390×844、320×568以及早期/后期动画帧；按第一眼、标识、排版、留白、色彩、素材融合、动效、手机、文案、细节十项评分，平均≥8、最低≥7。首轮必须记录最弱三项并修正后再次截图。验证聊天、创建编辑角色、用户/会话切换、记忆展开、上下文工具、统计tooltip、键盘与减少动态效果。上线前保留当前源码/数据库备份；纯前端更新不改角色、提示词或记忆框架。

## 首轮视觉复核与修正

1440px首轮截图确认主要结构与品牌已建立，进一步修正三处：品牌字标由32增至34px、完整中文标题由12增至13px；底部模型与统计字号由10增至11px并将指示器点击高度提高到34px；左侧已关闭的上下文折叠项改为细分隔行，保留展开项的白色容器，降低连续小卡片的噪声。手机快捷按钮统一44px。窄屏截图使用明确设置CSS viewport的浏览器；Chrome CLI最低窗口宽度产生的裁切图不作为验收证据。
