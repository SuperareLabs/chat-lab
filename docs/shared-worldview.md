# 好奇学院共享世界观

本地 ChatLab 按 `config/shared-prompts.json` 的明确角色范围加载共享内容。当前只给鳄鱼爸爸加载 `config/shared-worldview.md`，林小满、大肥鱼、林晚晴的实际提示词保持不变。

模型输入顺序为：通用规则、共享世界观、名称和人物设定。人物设定全文不改；布爸的 AI 与 App 主入口定位、日常字数条数、主动接话方式继续由其现有设定约束。实际可执行能力以当轮工具为准。

共享内容采用2026-11-17从 dev 管理页读取、由用户确认的本地适配稿。与后台原文的差异只有布爸的新主责和跨领域基础回应两处。后台未改动，本地使用固定快照，不自动跟随后台变更。

后台的“对话节奏与回答长度”没有加载，继续使用当前默认1条、必要时2～3条、每条通常5～20字且最多30字的要求。

共享文件与人物定义分开保存，不把世界观复制进每个人物。服务启动时读取共享配置，每次实际聊天都按角色范围组合，包括工具返回后的继续回答。提示词详情的 `sharedPrompts` 与完整 `system` 可用于核对加载情况。

共享配置变动只更新浏览器工作区内的配置哈希，使旧提示词视图失效；不重置数据版本，也不重写人物定义、用户、会话、消息或记忆。历史会话里记录的旧模型输入保留原样，下一轮才使用新的共享背景。

需要撤回共享层时，将共享配置的 `prompts` 置为空数组并重启服务；保留新增的快照配置哈希兼容，不直接恢复不认识该字段的旧快照校验器。
