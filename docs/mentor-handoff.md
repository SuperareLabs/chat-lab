# 角色推荐与转介

## 角色推荐

- 外层语义判断读本轮发言、相关前文、当前角色专长，以及理解「那我不去了」所需的当前卡片。找人、查角色、跨专长知识或任务、回应推荐时交给 `find_mentor`。搜索按独立请求判断。
- 只查公开定义、原文、链接或出处时，走搜索。需要辨认近期专业成果并匹配学科解释时，先搜索再交给导师工具。孩子明确要求不用联网时，该轮关闭搜索。
- 外层判断同时识别明确的数值计算请求。想知道数值、代入公式或核算结果就安排 `calculate`，只问原理或方法时由当前角色解释。搜索和计算同时需要时，先取得公开资料，再做数值运算，最后结合工具结果回复。计算工具支持精确算术，以及标明近似的常用科学运算。公式估值和需要来源的精确统计分别处理。
- `find_mentor` 读可用角色和本会话推荐记录。明确找可用角色时当轮出卡。查角色时介绍。孩子接着确认谁能帮正在聊的具体问题时，按前文判断。方向宽时接住话题，介绍确实合适的方向并问一句。常见词义和简单事实先简答。专业进展、复杂知识、学习、练习或具体任务由更合适的角色承接时，先提供简短帮助，再出卡。涉及当前研究消息时，联网核对与匹配辅导角色可以在同一轮完成。
- 推荐记录按实际目标去重。追问或换说法仍是原需求。明确拒绝后同一需求继续聊。独立的新需求可以马上评估。明确改主意找人按最新意图处理。名册采用已核对的十二位角色专长。布爸负责 AI 原理、AI 实践、学习方法和陪伴，考特负责编程、网络、设备与软件操作。

## 卡片与时效

- 成功发布的卡片归到产生它的助手消息。卡片展示本次如何帮忙，只有「找某某」。每张卡以来源回合 ID 标识。
- 同会话的下一张角色推荐卡写入成功时，在同一事务内把上一张可用同类卡置为已替换。模型识别明确拒绝并返回匹配的卡 ID 后，服务端确认它仍属于本会话的待处理卡，即时推送灰态。普通追问按当前角色继续聊。
- 会话闲置从服务端接收最后一条用户消息开始计算，满 15 分钟结束。历史卡保留在原处。进入界面、回前台、到达服务端提供的时间点时查询会话状态。到点向服务端核对后显示灰态。点卡由服务端再验证归属、会话期限、卡片状态和目标角色可用性。

## 转介与私有上下文

以既有 `runs.mentor_recommendation` 保存卡片快照和转介事实。按来源卡只接受一次转介，同一操作重试复用该记录。

1. 点卡后由服务端选择同一孩子和目标角色的有效会话，或者新建会话。先返回这个会话，App 成功加载后确认到达。到达时间记在来源卡上，原会话安静更新卡片状态。
2. 确认到达时，把来源角色、原问题、目标和已知进度抄送到目标会话的私有转介背景。卡片展示之后又聊过相关内容时，只在本次转介过程中补充进展，将结果写入目标会话。原卡记录状态、到达和欢迎消息 ID，目标会话保存实际交给模型的内容。
3. 目标角色用本会话的摘要主动欢迎。新会话先打招呼，顺口带上孩子从哪来、想聊哪件事，让孩子接下一句。已有对话时用熟悉的语气接回实际话题。讲解、练习和出题从孩子开口后的正常对话开始。欢迎失败时，已交付背景仍可用于正常回复。首条用户消息前目标会话过期时，把背景转存到实际接收这条消息的新会话。重试复用已送达摘要，孩子已经开始聊天时，由正常回复承接。
4. 原角色收到真实聊天消息时，按孩子和原角色找到最近成功的转介，读取目标角色和当时的目标作为私有历史背景。旧会话结束后也可查。提示词要求先回应眼前的话，相关时自然接上，只说已确认的事实。会话详情和前端模型调试输出只展示公开消息与允许公开的运行信息。

## Demo 接口与验收

- `GET /api/sessions/:id/status` 返回 `sessionId`、`status`、`serverNow`、`expiresAt`。聊天详情返回 `mentorCards`，每项包含 `id`、`messageId`、`mentor`、`copy` 和 `state`。
- `POST /api/mentor-handoffs` 接收 `childId`、原 `agentId`、`cardId`，返回目标 `agentId` 和准备好的 `session`。目标界面加载后用 `POST /api/mentor-handoffs/:cardId/arrive` 提交 `childId`、目标 `agentId` 和目标 `sessionId`，记录到达并生成欢迎。
- `mentor_recommendation` 事件带 `card`。明确拒绝或同类替换通过 `mentor_card_updated` 通知，含 `sessionId`、`cardId`、`state`。卡片状态为 `available`、`declined`、`superseded`、`expired` 或 `visited`。
- 验收覆盖同一问题换角色、只问知识词、明确点名、宽泛澄清、同目标连续追问、即时拒绝、独立需求替换、15 分钟边界与历史恢复、复用目标会话、欢迎去重、转介摘要随会话保存、私有背景隔离、公式数值计算，以及同轮搜索与计算。
