# 展示素材

本基线保留聊天界面所需的角色图片和图标，图片路径均指向仓库内文件。

| 文件 | 来源说明 |
| --- | --- |
| `public/assets/benny.png`、`benny-portrait.webp` | 原项目中的鳄鱼爸爸角色素材。 |
| `public/assets/agent-gallery-scene.webp` | 原项目中的角色图鉴背景素材，保留作展示资源。 |
| `public/assets/lin-xiaoman-guoman.png` | 为原项目生成的林小满角色立绘。 |
| `public/assets/pinecone.svg` | 原项目的松果测试角色图。 |
| `public/assets/dafeiyu-portrait.png` | 本次角色库使用内置ImageGen生成的蓝色小鲸鱼，透明PNG。 |
| `public/assets/chen-fang-portrait.png` | 本次角色库使用内置ImageGen生成的陈放立绘，透明PNG。 |
| `public/assets/a-mo-portrait.png` | 本次角色库使用内置ImageGen生成的阿墨黑猫，透明PNG。 |
| `public/assets/tang-li-portrait.png` | 本次角色库使用内置ImageGen生成的唐梨立绘，透明PNG。 |
| `public/assets/zhou-yu-portrait.png` | 本次1.2.0封版使用内置ImageGen单次生成的周屿胸像，参考上批插画风格，透明PNG。 |
| `public/assets/fonts/manrope-latin.woff2` | Google Fonts 的 Manrope 可变英文字体，200—800字重，24KB；来源 `https://fonts.gstatic.com/s/manrope/v23/xn7gYHE41ni1AdIRggexSvfedN4.woff2`，随附 `Manrope-OFL.txt`。 |
| `public/assets/icons/` | Bootstrap Icons；原始许可见同目录的 `LICENSE`。 |

本次版本归档没有为角色图像、声音或代码新增许可条款。第三方图标保留其原有许可。

私人参考录音没有进入公开仓库，公开角色配置也没有默认试听入口。`voice` 仍是可选展示配置；核心文字聊天和记忆流程不依赖音频。
