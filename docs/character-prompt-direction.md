# 角色提示词的编写与搜集方向

这份文档用于寻找适合“全Agent轻量聊天”的角色提示词参考。目标是让不同角色有自己的聊天感觉，最终配置只有：**名称＋一段角色设定**。

## 1. 在我们框架里怎么写

名称单独填写。角色设定用几段自然语言写清楚：他是谁、性格怎样、怎么说话和接话、擅长什么。背景有需要再写，少量对话示例可以一起放进去。

性格尽量落到反应上。例如，“有点爱面子，别人打趣时会轻轻还嘴，自己说错了也肯认”，比只写“幽默、温暖、有个性”更便于表达想要的效果。

可以从这样的草稿开始，再改成角色自己的口吻：

```text
你是[身份]，大家叫你[名称或昵称]。你[几个主要性格特点，以及这些特点怎样体现在聊天里]。

平常[语气、用词和说话节奏]。对方分享小事时，你[怎样回应]；开玩笑时，你[怎样接]；认真请教时，你[怎样讲清楚]。

你擅长[大方向]。[与聊天有关的背景，有需要再补。]

下面是语感示例，学接话的方式，台词随场景变化：
对方：[一句日常表达]
你：[符合这个角色的自然回应]
```

这些内容都放在同一个“角色设定”文本框里，自由取舍。工具调用、联网、记忆读取与提取由框架负责，角色提示词集中表达人物和聊天方式。

## 2. 联网上主要找什么

优先找**完整角色提示词＋连续几轮对话示例**，重点看日常陪伴、熟人聊天、自然打趣和有分寸的情绪回应。热情、克制、冷幽默等不同风格都可以参考。

几个已核对的参考入口：

- [SillyTavern 角色设计](https://docs.sillytavern.app/usage/core-concepts/characterdesign/)：看角色描述和对话示例的写法。其示例包含剧情旁白，按我们的文字聊天场景取舍。
- [Character.AI Definition](https://book.character.ai/character-guide/character-attributes/definition.md)：看如何用一段自由文本和示例对话表达角色。
- [Character Card 原始规范](https://github.com/malfoyslastname/character-card-spec-v2/blob/main/spec_v2.md)：遇到角色卡时，可重点读取描述、性格和示例对话；卡片格式本身不代表聊天效果好。

## 3. 找到以后怎么适配

先看连续对话：有没有接住对方刚说的具体内容，玩笑能不能往下接，说够后能不能停住，认真问题能不能展开。只有人设标签、长篇背景或单句金句的材料，参考价值有限。

保留有用的人物特点、接话方式和示例，整理成一段自然语言；去掉其他平台的占位符、工具协议、记忆流程和重复规则。口头禅少量使用，避免每轮都像在重复同一段表演。

将候选设定放进我们当前同一个模型和框架，用相同的几句日常聊天对照，观察角色区别、接话自然度和回复长短。外部文档只能提供写法参考，实际效果以这里试聊为准。
