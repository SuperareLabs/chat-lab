## 本次发布

- 默认展示林小满、鳄鱼爸爸、大肥鱼、林晚晴。其他系统角色隐藏归档，历史文本、会话和记忆保留；用户自行创建的公共角色不清空。
- 鳄鱼爸爸保留原性格、接话节奏和日常话量，只补强AI导师部分：具体示范、换讲法、修改结果、独立核实、逐步少帮和能力诚实。共享学院世界观按角色范围接入。
- 模型明确返回消息数组，每项是一条消息；一条内部可以有多个段落或代码块。前端不根据换行猜气泡数。格式异常最多修正一次，已有工具结果复用，不重复执行工具；两次模型用量均记录。
- 计算器使用有界的BigInt有理数运算，大整数和有限小数保留精度，循环小数标明近似与精确分数，错误返回具体原因。
- 后台刷新仅在当前内容确实变化时更新，保留草稿、会话与滚动位置；补齐网络错误和耗时诊断。
- 修复跨会话重复提及记忆后的浏览器快照校验，沿用记忆框架6。已核对线上1.2.0指纹在数据保留兼容清单中，发布不重置用户工作区。
- 主聊天采用DeepSeek 4.1 Flash 1017经济版，思考关闭；记忆与搜索模型保留现有配置。

日常规则仍为默认1条，必要时2～3条，每条通常5～20字、最多30字；明确要求详细解释、长文或代码时允许展开。话量由提示词约束，没有机械截断模型回复。

## 部署与回滚

按[部署说明](../deployment.md)从已提交代码创建源码归档，校验SHA256，对现有公共角色库做一致备份，再切换release软链接并优雅重启。旧release、服务文件和外部配置均保留。

服务重启后需要重新输入原口令。保持原Origin和数据库路径，不通过清空浏览器或数据库解决升级问题。已经接收1.3.0元数据的浏览器不承诺可直接降级到未经适配的1.2.0；出现问题应优先保留快照并修复兼容性，不能重置用户资料。
