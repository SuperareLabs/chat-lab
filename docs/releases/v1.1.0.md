# 1.1.0

封版日期：2026-11-13。分支：`version1.1.0`。标签：`v1.1.0`。

本版接入手动角色创建与编辑。表单仅有名称、完整角色设定两项，原文保存在 SQLite；保存后下一轮聊天使用新设定，编辑沿用原角色 ID 和记忆作用域。并行编辑用修订号检测冲突，冲突时保留草稿。

角色图鉴统一展示实际保存的原文，可查看后端完整提示词。新数据库不自动预装角色；已有数据库按原 ID 一次性导入，后续重启以数据库为准。已有头像、受众限制及可选参考音元数据保留。

林小满的角色设定已收整为一段，采用日常 1—3 条、每条尽量 30 字的短句节奏；认真问题按需展开。平台继续提供四个工具、用量及费用展示、按需记忆读取和最多500条活跃记忆的更新／归档机制。

本次把开发内部版本 `1.3.16` 统一标为正式 `1.1.0`，未改变记忆框架6和平台数据指纹，封版操作不重置运行数据。私人数据库、聊天记录、备份、凭据和参考录音不进入公开源码。

验证：216项本地模拟模型测试通过；独立浏览器验证创建、编辑、原文换行、会话保留、取消和窄屏布局。本次封版不调用付费模型。真实模型表现及当前检索边界见[已知限制](../known-limitations.md)。
