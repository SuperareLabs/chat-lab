# 1.1.2

封版日期：2026-11-15。分支：`version1.1.2`。标签：`v1.1.2`。

本版固化当前聊天 Demo：统一聊天工作台、角色图鉴、表单和用量展示；移除顶部 Chat Lab 品牌栏、播放按钮与独立全屏片头，让聊天区获得更大的宽度与高度。

每次刷新由聊天界面自然进入。纯 CSS 淡入和8px轻位移动画优先展示聊天，随后展示工具栏与辅助面板，全部约520ms结束。没有专用 JavaScript、存储标记、模态遮罩或等待动画后才可操作的逻辑；系统开启减少动态效果时直接显示。

角色创建仍只填写名称与完整设定；已有聊天、四个工具、用户概括及记忆提取／按需加载／归档机制保持原行为。记忆框架仍为6，平台数据指纹不变，封版不重置角色、用户、会话或记忆。公开源码不包含本机数据库、凭据、聊天记录或私人参考音频。

验证记录：216项本地模拟模型测试通过；1440×900、390×844、320×568浏览器验收无文档横向溢出，连续两次刷新都触发进入动画，减少动态效果、输入与角色选择正常，控制台及网络检查无错误。本次封版只更新发布文档，无新增付费模型调用。
