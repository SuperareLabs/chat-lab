# 1.2.0 首次封版快照（历史标签）

封版日期：2026-11-16，历史标签 `v1.2.0` 对应 `358e6ef`。本页记录当时的首次封版；当时尚未部署公网。后续的角色排序、默认用户及公共角色库已合入持续维护的 `version1.2.0` 分支，当前线上配置见[部署说明](../deployment.md)。下列功能与252项验证记录属于原始标签，不代表维护分支的最新状态。

- 服务端共享口令入口、退出与进入状态，口令不进仓库或前端。
- 默认公开模式：IndexedDB保存在访客浏览器，服务器只临时内存处理，默认8公开角色与匿名访客。
- 名称＋角色设定的创建/编辑、消息、会话、工具、记忆、概括和usage保持原逻辑；各浏览器独立。
- 首次4步引导，可跳过/重开；介绍选Agent、创建角色、资料与新会话、本地记忆与清空。
- 清当前用户×Agent记忆，二次确认，保留历史与其他范围，打开新会话；旧任务和上下文不能复活已清记忆。
- 多标签租约/revision CAS、消息本地草稿和中断恢复，自动整理在页面到期/重开时补齐，无自动付费重发。

- 默认8位角色入库，补齐这批角色图和周屿头像。
- 大肥鱼、陈放、阿墨、唐梨采用明确分条与字数规则：日常默认1条，必要时2～3条，每条最多30字；明确要求详细再展开。
- 未改动过的默认角色受控升级，私人编辑与自建角色保留；已有历史和记忆不重置。

原私有SQLite和旧封版代码保留，不导入公开访客，也不重置。记忆框架仍6，共用规则与记忆提取提示词未因本次功能而修改。本次固定的是功能与源码，模型语义和真人感仍受已知限制约束。

## 验证记录

- 252项完整自动测试通过；覆盖进入认证、本地隔离、清空防复活、受控默认角色升级及并发修订。
- 独立小样本收短复测：4角色共24次日常回复，每条均在30字内，最长24字；21次单条、3次两条。4条明确要求详细的问题均能展开。字数是提示词约束，没有对生成结果机械截断，不构成所有真实场景的长度或语义保证。
- 上轮已跑通真实聊天→记忆提取→恢复→清空与真实浏览器基础流程。模型的分寸和事实错误仍按known-limitations保留，不把收短等同于真人感或语义全面通过。
